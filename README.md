# Nano Escape + Signal

Nano Escape is a cyberpunk survival game built with Python and Pygame. Evade
hunter drones, collect energy orbs, and survive the 60-second lockdown. The
desktop version runs offline; a browser build is also available for desktop
and mobile browsers.

## Requirements

- Python 3.10 or newer
- Pygame 2.x
- Windows, macOS, or Linux with a display and keyboard

The game code is in [`main.py`](./main.py). Graphics and sound effects are
generated by the game, so no image or audio assets are required.

## Play in a browser

The game can be hosted for free on GitHub Pages. The included GitHub Actions
workflow builds the browser version and publishes it whenever changes are
pushed to `main`.

1. In the repository's **Settings → Pages**, set the build and deployment
   source to **GitHub Actions**.
2. Push the repository to GitHub. The first build may take a few minutes.
3. Play at <https://babusinu986-chiki.github.io/Nano-Escape/>.

The browser build uses Pygbag and downloads its Python WebAssembly runtime the
first time it loads, so an internet connection is required. On a phone, rotate
to landscape for the intended game layout. Use the on-screen directional pad
and tap the start/restart button; keyboard controls remain available on desktop.

## Install and run

Open a terminal in the Nano Escape project folder.

### Windows PowerShell

Create and activate a virtual environment, then install Pygame:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install pygame
python main.py
```

If PowerShell blocks environment activation, run the game using the virtual
environment's Python directly:

```powershell
.\.venv\Scripts\python.exe -m pip install pygame
.\.venv\Scripts\python.exe main.py
```

### macOS or Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pygame
python main.py
```

Pygame is the only package to install. Once installed, the game runs locally
without an internet connection.

## How to play

1. Start the game and press **Enter** on the title screen.
2. Wait for the **3, 2, 1, GO** countdown. The survival timer starts when
   gameplay begins.
3. Move around the arena, collect energy orbs, and avoid hunter drones.
4. Survive until the 60-second timer expires to complete the mission.

## Controls

| Input | Action |
| --- | --- |
| **W**, **A**, **S**, **D** | Move up, left, down, and right |
| **Arrow keys** | Move up, left, down, and right |
| **Enter** | Start from the title screen; restart after game over or after the victory sequence |
| **Escape** | Exit the game |

Movement is smooth, and pressing a horizontal and vertical direction together
moves diagonally.

## Rules and scoring

- Each run lasts **60 seconds**.
- The arena starts with **3 drones**. Drones pursue the player, and additional
  drones spawn over time, up to a maximum of **9**.
- Energy orbs appear around the arena. Collecting an orb adds **100 points**.
  Orbs respawn during play, with up to **6** available at a time.
- Touching a drone ends the run immediately in **Game Over**.
- If the timer reaches zero before a drone hits the player, the player wins.
  Gameplay freezes and a system-breach terminal sequence plays before showing
  the final score and restart prompt.
- Press **Enter** after Game Over to start another run. After a victory, wait
  for the terminal sequence to reveal its restart prompt, then press **Enter**.

## Audio and visuals

The game's cyberpunk visuals—including its animated grid, glows, particles,
screen effects, title screen, and victory terminal—are drawn by Pygame.

Audio is synthesized in memory by the Python code. It includes countdown
beeps, a quiet looping background tone during gameplay, an orb pickup sound,
a collision impact, and a dramatic sound when the victory sequence begins.
There are no bundled sound files.

If an audio device or Pygame mixer is unavailable, the game reports that
audio is unavailable and continues without sound.

## Troubleshooting

- **`No module named 'pygame'`**: activate the virtual environment and run
  `python -m pip install pygame`.
- **No sound**: check the system's output device and volume. The game can run
  without an available audio device.
- **Game window closes immediately**: launch it from a terminal with
  `python main.py` to see any error message.
